## Product

- Target: a single-player Ren'Py game on Windows. Mostly prose, with occasional colored `■` pictures. The player navigates bullet-marked options with W/S or the arrow keys, confirms with Enter or a click, and plays themself. Play is deduction and puzzle-solving. Scenario modules use a Call of Cthulhu–style TRPG shape. Fiction is the world of The Melancholy of Haruhi Suzumiya. Contract: `Docs/GAME_DESIGN.md`.
- Current implementation: the full scenario 0 Markdown module and the Ren'Py project for Hook, S00–S16, K01–K10, H01–H04 (plus H01_REVISED), and E01–E03, with one JSON save, scoped send-back cleanup, character-by-character text, and W/S choice menus.
- 2026-10-21: The console cursor and Chinese character-width bugs are why the playable runtime left `System.Console`. The window is dark, with cyan dialogue and cyan selected choices.

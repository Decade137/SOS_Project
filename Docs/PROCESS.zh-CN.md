# 流程

英文 `Docs/PROCESS.md` 为准。本文件只复述同一批事实。

## 工作规则

- 改文件前的阅读顺序：`AGENTS.md` → `Docs/MEMORY.md` → `Docs/PROCESS.md` → `Docs/STRUCTURE.md` → `Docs/GAME_DESIGN.md` → 其他功能文档。
- 默认做静态核对。没有明确要求时，不启动引擎、测试或构建。
- 每个工作会话追加一条简短的日期记录。
- 只有一条 PROCESS 记录不够用时，才写 `Docs/LOGS/YYYY-MM-DD-topic.md` 和中文镜像。
- 不调整历史会话记录的顺序。
- 中英文不一致时，以英文为准，并在同一次会话里修正镜像。
- 除非用户要求，不运行 Unity、不创建 Unity 工程，也不把上一级文件夹的名字当成引擎选择。

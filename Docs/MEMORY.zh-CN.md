# 记忆

英文 `Docs/MEMORY.md` 为准。本文件只复述同一批事实。

## 技术栈

- 仓库：git，分支 `main`，远程 `https://github.com/Decade137/SOS_Project.git`。
- 选定的运行时：Ren'Py 8.5.3。工程在 `Play/`。`pack.bat` 会打出 Windows x64 游戏目录 `Build/SOS_Project/SOS_Project.exe`。玩家不必安装 Ren'Py。Ren'Py SDK 只在打包时下载到被忽略的 `tools/`。打包产物被忽略在 `Build/`。
- 当前工作区是 `E:\UnityProject\SOS_Project\SOS_Project`。它不是 Unity 工程。
- 已停用的 .NET 10 控制台工程不在工作区里。`Game/`、`Scenarios/ZeroFloor.Play.cs` 和仓库根目录的 `SOS_Project.exe` 都已删除。打好包的游戏是 `Build/SOS_Project/SOS_Project.exe`。先前的 `dist/` 输出目录已删除。

## 产品

- 目标：Windows 上的单人 Ren'Py 游戏。以正文为主，偶尔用彩色 `■` 图。玩家用 W/S 或方向键在圆点选项间移动，按 Enter 或点击确认，并扮演自己。玩法是推理解谜。剧本模块用类似《克苏鲁的呼唤》（COC）跑团的结构。故事世界是《凉宫春日的忧郁》。约定见 `Docs/GAME_DESIGN.md`。
- 当前实现：已有第 0 号完整 Markdown 剧本，以及涵盖开场、S00—S16、K01—K10、H01—H04（另含 H01_REVISED）、E01—E03 的 Ren'Py 工程，含一份 JSON 存档、送返结局的限定范围清理、逐字显示与 W/S 选项菜单。
- 2026-10-21：控制台光标和中文宽度问题是可玩版本离开 `System.Console` 的原因。窗口为深色，对白和选中项为青色。

# 长篇写作：故事圣经

写到几万字以后，最容易出问题的不是文笔，而是一致性：伏笔忘了回收，人物口吻走样，时间线自相矛盾。AI 尤其容易出这种问题，因为前文会被挤出上下文。

解决办法：维护一份**故事圣经**，每写一章前读它，写完一章后更新它。正文可以很长，但圣经要始终保持短小，能一次读完。

## 1. 故事圣经的结构

```markdown
# 故事圣经：〔书名〕

## 真相（作者可见）
3–5 句真相段。写完全书前不改，要改就记下改动日期和原因。

## 核心问题
1–3 个。

## 世界规则
每条一句话。写清能做什么、不能做什么、代价是什么。

## 时间线
按真实时间排序（不是叙述顺序）。每条：日期／时间｜事件｜谁知道。

## 人物现状
每人一段，只写“此刻”的状态：
- 想要（当前）
- 知道什么（当前，列证据编号）
- 和谁的关系变了
- 身上的伤、手里的物件、所在地点
- 声音指纹（不变的部分）

## 伏笔账本
| 编号 | 内容 | 埋在 | 计划回收 | 状态 |
|---|---|---|---|---|
| F01 | 柜门上的划痕 | 第 2 章 | 第 9 章 | 已埋 |

状态只用三种：计划、已埋、已回收。

## 母题表
每个母题：出现过的章节，以及每次的含义变化。

## 称呼与用语表
谁怎么称呼谁；专有名词的统一写法；某个角色从不说的词。

## 章节摘要
每章一条，见下文。
```

## 2. 章节卡

每章动笔前填：

```
第 N 章：
视角人物：
时间与地点：
本章要改变的事：（处境／认知／关系，至少一项）
交付的证据或信息：
埋设：（伏笔编号）
回收：（伏笔编号）
语气：（在全书语气曲线上的位置）
章末钩子类型：
```

## 3. 每章的工作循环

```
- [ ] 1. 读故事圣经：真相、人物现状、伏笔账本、上一章摘要
- [ ] 2. 填章节卡
- [ ] 3. 写正文
- [ ] 4. 自检：人物是否知道了他不该知道的事？时间线对得上吗？称呼对吗？
- [ ] 5. 更新圣经：人物现状、伏笔状态、时间线、母题表
- [ ] 6. 写本章摘要
```

第 5 步不能省。不更新圣经，第三十章就会出错。

## 4. 章节摘要的格式

每条不超过 150 字，只记“状态变化”，不复述情节：

```
第 7 章｜视角：林安｜时间：十月三日夜
变化：林安得知账本被人撕过一页（证据 K04）。她和老陈的关系从信任变为戒备。
埋设：F06 撕页的边缘有蓝墨水。
回收：F02 老陈第 3 章说过“我从不用蓝笔”。
章末：老陈敲门。
```

这样的摘要可以直接交给下一次写作的 AI，作为上下文的最小交接。

## 5. 长篇节奏

- **每三到五章一次小揭示**，推翻一个误读，或者交付一条关键证据。
- **中点翻转**：全书一半左右的位置，主角对核心问题的理解发生一次根本变化，从“我在找什么”变成“我在躲什么”这一类。
- **每一卷有自己的小问题和小结局**，同时推进全书的大问题。
- **语气曲线放大到全书**：标出每一卷的基调，以及整部作品的转折章节。

## 6. 章末钩子

钩子的类型要轮换，不要每章都用同一种：

- **新信息**：一条推翻先前理解的事实
- **到来**：有人敲门、电话响了、信到了
- **选择**：主角决定了某件事，但还没去做
- **悬置的动作**：手放在门把上
- **安静的反常**：本该发生的事没有发生

偶尔可以没有钩子，用一个安静的收尾让读者喘口气。连续十章都是悬崖式钩子，读者会疲惫。

## 7. 多线交织

- 每条线有自己的问题和节奏，但最终交汇在同一个事件上。
- 切线的时机：在一条线的小高点或小悬念处切走，而不是在平淡处。
- 两条线的信息可以互相照亮：A 线里读者知道的事，正是 B 线里人物不知道的事。

## 8. 回顾的写法

长篇里读者需要偶尔被提醒前情，但不要写成复述：

- 机械：“正如前文所说，三年前那场大火……”
- 生动：让人物碰到一个和前情有关的物件或场景，用一句话带出来。“他又闻到了焦味。这次只是邻居在烤红薯。”

## 9. 防止人物走样

- 每写五章，重读一遍人物的声音指纹，再遮住名字读本章对白。
- 人物的变化必须在圣经里有记录，并且由具体事件触发。圣经里没有记录的变化，就是走样。
- 能力和知识只能通过正文里发生的事增加。

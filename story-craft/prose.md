# 行文

## 1. 总原则

- **具体胜过概括。** 写“粉笔灰和旧木头的气味”，不写“充满怀旧气息的房间”。
- **名词和动词干活，形容词休息。** 一个准确的名词胜过三个形容词。
- **短句为骨。** 大多数句子短而直；偶尔用一个长句承载一串连续的动作或累积的细节。
- **克制。** 越重要的时刻写得越少。
- **信任读者。** 读者能从动作里读出情绪，不需要旁白翻译。

## 2. 开场

- 前三句之内出现具体的感官细节：声音、气味、温度、光。
- 从动作或异常进入，不从背景介绍进入。
- 第一段结尾给出一个让人想读下一句的小异常。

机械开场：“这是一个平凡的夏日午后，阳光明媚，主人公像往常一样……”

生动开场：“上一秒，我还在推一扇再普通不过的门。迎面扑来的却是蝉声、旧木头和粉笔灰的气味。”

## 3. 情绪的写法

情绪通过四种渠道出现，不通过旁白报告：

1. **身体**：手停在半空、眉心被揉了揉、喉咙发紧（少用，最多一处）
2. **物件**：茶杯放下了、纸被对折、手机收回口袋
3. **对白**：话说了一半、问了别的事、换了称呼
4. **停顿**：没人接话、看了很久没有翻页、什么也没说

一个场景里，情绪最强的那一刻往往是最安静的那一刻。

## 4. 对白

- 对白标签只用“说”“问”。不用“咆哮道”“轻笑道”“冷冷地说”。
- 能从内容判断是谁说的，就不加标签。
- 对白里不出现双方都知道的信息（“你也知道，我们三年前……”）。
- 角色很少直接回答问题：他反问、转移、只答一半，或者先看另一个人。
- 让对白和动作交错。一句台词后面跟一个小动作，比一串连续台词更有呼吸。
- 一个人长篇解释设定时，打断他：别人插话、手机响了、有人回来了。

## 5. 场景收尾

最后一句落在以下之一：

- 一个图像：“墙上的挂钟走到十二点。然后，没有再走下去。”
- 一个悬置的动作：“窗边那个女孩的视线从日历移到我身上，停住了。”
- 一句没被回答的问话
- 一个打断：“前面，有人在喊我的名字。”

不落在：总结、感悟、预告（“他不知道，这只是开始”）。

## 6. 数字与时间

- 用精确数字：“三点十七分”“一万五千多次”“十一天前”。
- 同一个时间在不同场景重复出现，读者会自动把它当成证据。
- 数字还能制造喜剧：“对着夕阳发呆十七秒，判定为特别的反应。”

## 7. 喜剧节奏

喜剧是结构，不是俏皮话。常用的几种：

- **一本正经的荒谬逻辑**：角色用完全自信的语气推出荒唐结论。“那就补到通过为止。”
- **三连递进**：问—答—再问—更离谱的答。第三拍是包袱。
- **装傻与吐槽**：一个人提出离谱主张，另一个人用最平常的事实回应。“那个柜子里是拖把和水桶。我上礼拜刚从里面拿过拖把。”
- **预期反转后的群像反应**：一件事的结果出乎意料，然后用一句话写完每个人的反应。“我走过去，只用了一分钟。出题的人很失望，陪考的人很欣慰，还有一个人说，这证明考生的空间感优于常人。”
- **正经格式装荒唐内容**：成绩单、公告、会议记录。

注意：

- 包袱放在句末。包袱后面不解释，直接进下一件事。
- 喜剧场景也要交付背景层的信息。
- 转向严肃以后，笑点不要一刀切掉，而是逐渐减少、变短。

## 8. 悬念与留白

- 一个人知道而不说，比一个人说出来更有悬念。写他“看了一眼屏幕，什么也没说，把手机收了回去”。
- 关键结论出口之后，写屋里的反应，而不是写结论对不对。“没有人说我错了。”
- 不要在揭示后补一段解释“原来是这样”。读者已经懂了。

## 9. 叙述视角

- 定好视角就不越界。第一人称不知道别人在想什么，只能看见他们做了什么。
- 第一人称的“我”也少写“我觉得”“我意识到”。直接写看见的、做的、说的。
- 第二人称（交互作品常用）同样适用：不写“你感到害怕”，写“你的手停在门把上”。

## 10. 禁用表达

下面这些表达一出现，文字立刻变得机械。写完后全文检查，能删就删，不能删就换成具体的动作或物件：

**情绪报告**：感到、觉得心里、心中五味杂陈、百感交集、一股暖流、不由得、不禁、忍不住

**模糊修饰**：一丝、一抹、些许、仿佛、宛如、似乎（连续出现时）、某种难以言喻的

**套路动作**：嘴角勾起一抹弧度、眼中闪过一道光、深吸一口气、空气仿佛凝固了、时间仿佛静止了、心跳漏了一拍

**升华收尾**：这一刻他终于明白了、或许这就是……的意义、一切都会好起来的、新的篇章即将开始、命运的齿轮开始转动

**翻译腔（中文写作）**：进行了一个……的动作、被……所……、长串“的的的”定语、“作为一个……”开头

**说明腔**：众所周知、值得一提的是、不得不说

例外：角色台词里，符合该角色说话习惯的套话可以保留。禁用的是叙述者的懒惰，不是角色的个性。

## 11. 矫枉过正

上面的规则是用来治“机械”的药，吃多了会得另一种病：文字变得冷淡、干瘪、故弄玄虚，同样不生动。规则是手段，目标始终是读者读得进去、读得懂、被打动。

| 病症 | 表现 | 解药 |
|---|---|---|
| 碎句病 | 每句都很短，读起来像电报，节奏单调 | 长短句交替。连续动作、累积的细节、人物的思绪，适合用长句一口气推下去 |
| 冷漠病 | 删光了所有情绪，人物像木头 | 克制是为了让少数直白的时刻更重。前文足够克制时，一句直白的“我很想他”反而最有力 |
| 谜语人病 | 为了留白，连读者看懂场面需要的事实也藏起来了 | 藏答案，不藏场面。读者随时要知道谁在场、在哪里、身体上发生了什么 |
| 细节清单病 | 把“具体”理解成罗列一串感官名词 | 每个节拍只挑一两个最能说明问题的细节，其余删掉 |
| 结尾套路病 | 每一场都停在一个意味深长的图像上，成了新的套路 | 收尾方式轮换：图像、对白、打断、一句平实的事实，偶尔干脆利落地结束 |
| 母题过载 | 同一个物件每页都出现，读者开始厌烦 | 一个母题在全文出现三到五次就够了，每次意义都要往前走一步 |
| 代价强迫症 | 每个结局都很惨，为虐而虐 | 代价可以很小，可以是温暖里的一点遗憾。温暖的结局是允许的 |
| 禁用词恐惧 | 为了避开禁用词而绕远路，句子变得别扭 | 禁用清单针对的是叙述者的偷懒。平实地用一次“觉得”没有问题 |
| 全员回避 | 所有人都不正面回答问题 | 回避要有对照。总得有人说真话、直接回答，回避才显得出来 |
| 喜剧硬塞 | 严肃场景里也非要放一个包袱 | 转折之后笑点减少。最重的场景里，一个笑话都不要 |

判断标准：读一遍，如果读者需要停下来猜“这里发生了什么”，就是藏多了；如果读者觉得“我知道，不用说了”，就是写多了。

## 12. 修订顺序

写完后按这个顺序修：

1. 删掉每段结尾的总结句和感悟句，看段落是否更好。
2. 把情绪报告换成动作或物件。
3. 清理禁用表达。
4. 每个场景最后一句检查一遍。
5. 遮住名字读对白，认不出的角色改句式。
6. 找出最重的那一段，把它砍短。
7. 最后对照上一节，检查有没有矫枉过正：句子长短有没有交替，有没有一处直白的情感，场面是否清楚。
